AVIATOR AI PRO — iPHONE WEB APP STARTER

Included:
- index.html: responsive dashboard with charts, multiplier range distribution, statistics, target tracking, CSV export and test notifications
- manifest.json: web-app metadata
- sw.js: minimal service-worker shell

How to try:
1. Extract the ZIP on a computer or supported file manager.
2. Open index.html in a modern browser to test the dashboard.
3. To add it to the iPhone Home Screen, host all files on an HTTPS website, open the hosted page in Safari, tap Share > Add to Home Screen > enable Open as Web App > Add.

Limitations:
- This version does NOT connect to SportyBet or collect live results automatically.
- It cannot see a current live multiplier, predict the next crash, or automatically cash out.
- Background push notifications need a hosted push service and server; this starter supports only permission/test alerts when the page is active.
- Direct SportyBet integration requires an authorised supported data feed. SportyBet's public help pages do not document a public Aviator API; ask official support before attempting any integration.

Never enter passwords, PINs, OTPs, or session tokens in this app.
